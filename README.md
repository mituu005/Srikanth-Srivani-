## Features
- Interactive hero section with couple details
- Moments photo gallery
- Wedding celebration schedule cards
- Live countdown timer
- Venue details with Google Maps direction link and QR code
- RSVP with contact information
- Falling petals animation

## Getting Started
Open `index.html` directly in your web browser, or serve locally with Node.js:
```bash
node server.js
```
or with Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
